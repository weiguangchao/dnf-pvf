# 战斗对象与状态效果功能索引

被动对象、附加状态、属性修正和光环。

叶子手册按对象、动作、攻击定义、附加状态和光环分别追踪实际引用。包含重复标签和嵌套块的定位方法。路径均相对 output，目录名称不作为字段语义的证据。

## 功能范围

- 被动对象及技能生成对象。
- 对象动作、攻击判定和特效。
- 附加状态与属性修正。
- 时装光环与装备光环。

- [技能、怪物与装备生成对象](skill-and-equipment-objects/FEATURE_MAP.md)。角色技能、怪物、宠物和装备关联的被动对象。
- [场景机关与可交互对象](scene-action-objects/FEATURE_MAP.md)。场景动作对象、障碍、陷阱和可破坏对象。
- [投掷物与爆炸对象](throwable-objects/FEATURE_MAP.md)。投掷物生成的场景对象及关联攻击表现。
- [附加状态与属性修正](appendages/FEATURE_MAP.md)。攻击、属性、技能等级及装备相关的附加状态。
- [时装与装备光环](auras/FEATURE_MAP.md)。时装光环、装备光环和光环表现。
- [剧情与活动对象](cinematic-and-event-objects/FEATURE_MAP.md)。剧情过场对象及活动专用对象。

## 归类边界

本类记录对象、附加状态和光环的定义。对应的 Squirrel 脚本实现归入脚本与公共配置。
