# 地图与副本功能索引

城镇、区域、世界地图、地下城和关卡场景。

各叶子手册依据实际 output 样本记录标记、参数形状、引用和修改步骤。手册中的源路径均相对于 `output`。观测结果与玩法推断分别标明。未确认列义和二进制资源不提供猜测性改写公式。

## 功能范围

- 地下城定义与关卡配置。
- 场景地图、地块及场景动画。
- 城镇、区域与区域小地图。
- 关卡地图和世界地图。

## 子功能索引

- [地下城与关卡定义](dungeon-definitions/FEATURE_MAP.md)。地下城入口条件、等级、路线和起始及首领地图。
- [场景地图与地块](scene-maps/FEATURE_MAP.md)。场景布局、地块和场景动画资源。
- [城镇与区域](towns-and-regions/FEATURE_MAP.md)。城镇定义、区域划分和区域小地图。
- [世界地图与关卡地图](world-and-stage-maps/FEATURE_MAP.md)。世界地图、关卡地图及地图表现。
- [特殊副本与教学关卡](special-dungeons/FEATURE_MAP.md)。远古、异界、时空之门、安徒恩及教学等副本分组。
- [塔类副本与祭坛](towers-and-altar/FEATURE_MAP.md)。塔类关卡、塔层映射和祭坛配置。
- [战场、决斗场与城镇防御](battlefields-and-town-defense/FEATURE_MAP.md)。战场地图、决斗场景和城镇入侵关卡。

## 归类边界

本类记录地图、地下城与场景配置。任务条件归入任务与活动，怪物定义归入怪物与人偶。
