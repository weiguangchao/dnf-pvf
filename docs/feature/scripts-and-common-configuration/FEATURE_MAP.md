# 脚本与公共配置功能索引

跨功能脚本、公共资源、辅助数据和混合系统配置。

子功能依据解包目录、条目名称和抽样字段划分。条目线索用于说明归类依据。

## 功能范围

- 跨功能的 Squirrel 脚本。
- 通用动画、命中特效及状态表现。
- 技能和界面的辅助数据。
- 仓库、公会、组队、决斗平衡、掉落和频道等混合系统配置。
- 运营服务、商城积分及公共占位数据。

本类记录脚本、公共资源及跨功能服务配置。装备改造、商城和活动的功能编目由各自分类维护。
