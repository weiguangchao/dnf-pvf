# 任务与活动功能索引

剧情任务、日常任务、决斗任务和运营活动。

各叶子手册依据实际 output 样本记录标记、参数形状、引用和修改步骤。手册中的源路径均相对于 `output`。观测结果与玩法推断分别标明。未确认列义和二进制资源不提供猜测性改写公式。

## 功能范围

- 任务定义与任务索引。
- 决斗日常、晋级和重复任务。
- 活动规则及触发条件。
- 活动奖励。

- [紧急、深渊与特殊解锁任务](urgent-and-unlock-quests/FEATURE_MAP.md)。紧急任务及深渊、塔类、称号等特殊任务分组。

- [登录、签到与成长活动](login-and-growth-events/FEATURE_MAP.md)。账号登录、签到、创建角色和成长类活动。

## 归类边界

本类记录任务与活动规则的编目。任务窗口归入界面与交互，任务涉及的地图及物品由各自功能分类维护。
