# NPC 与商店功能索引

NPC、普通商店、商城商品和购买奖励。

各叶子手册依据实际 output 样本记录标记、参数形状、引用和修改步骤。手册中的源路径均相对于 `output`。观测结果与玩法推断分别标明。未确认列义和二进制资源不提供猜测性改写公式。

## 功能范围

- NPC 定义、名称与交互。
- 普通商店及 NPC 商品列表。
- 商城商品与时装抽取。
- 购买奖励。

## 子功能索引

- [NPC 定义与交互角色](npc-interactions/FEATURE_MAP.md)。NPC 身份、外观、交互角色和提示。
- [普通商店与 NPC 商品](ordinary-shops/FEATURE_MAP.md)。装备、消耗品、配方和特殊 NPC 商店。
- [商城分类与购买](cash-mall/FEATURE_MAP.md)。商城商品分类、礼包及购买限制。
- [时装抽取与轮盘](avatar-lottery/FEATURE_MAP.md)。按部位区分的时装抽取和轮盘商品。
- [特殊商店、积分与购买奖励](special-offers-and-mileage/FEATURE_MAP.md)。限时商店、积分商店、兑换及购买奖励。

## 归类边界

本类记录 NPC 交互与商品销售配置。物品本身归入装备与道具，商店窗口归入界面与交互。
