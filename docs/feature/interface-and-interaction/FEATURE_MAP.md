# 界面与交互功能索引

界面布局、客户端交互、快捷键和聊天表情。

叶子手册核对实际 UI 控件、父页与子文件绑定，以及输入配置中的数据形态。界面表现与玩法规则分别说明。路径均相对 output，未解析的二进制动画不提供猜测改法。

## 功能范围

- 界面布局与界面动画。
- 客户端菜单和技能树交互。
- 快捷键及输入配置。
- 聊天表情及关联动画。
