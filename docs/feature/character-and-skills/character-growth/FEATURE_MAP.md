# 角色成长与角色关联修改手册

## 入口与样本

经验表位于 `character/exptable.tbl`。关联配置至少有两个不同文件 `etc/characlinksystem.etc` 和 `etc/linksystem/characlinksystem.etc`。本页读取了三个文件。不能因为文件名相同就把两个关联文件当镜像。

## 原始序列与字段

- `character/exptable.tbl:2` 是无标签整数序列，共 99 个值。前五个是 `1000 2653 5543 10575 18509`。没有显式等级键，也没有行级记录分隔。按数组位置映射等级是推断，起始等级要通过客户端或调用方确认。
- 同一行第 95 个值为 `2127330010`，后四个为 `-2005093948 -1831470394 -1646186759 -1448695754`，见 `character/exptable.tbl:2`。这与 32 位有符号显示溢出的形状相符，但只是推断。不能把负数批量归零，也不能凭负号判定归档损坏。
- `[1st link character info]` 在 `etc/characlinksystem.etc:3` 内只有一条七整数序列 `60 0 0 70 0 0 70`。有显式结束标签。字段名能确认是第一关联角色信息，七列的门槛、奖励、范围归属尚未确认。
- `[2nd link character info]` 在 `etc/characlinksystem.etc:7` 为七整数 `40 15 0 59 15 0 50`。它与第一块列数相同，但不能因此认定所有列含义相同或百分比单位相同。
- `[link level]` 在 `etc/linksystem/characlinksystem.etc:3` 为一个整数 `50`。名称提示关联等级门槛。达到或超过的边界规则未从文件确认。
- `[low link character exp bonus]` 在 `etc/linksystem/characlinksystem.etc:5` 为四整数 `1 70 10 0`。`[high link character exp bonus]` 在第 9 行为 `1 70 0 0`。首两列可能为等级区间，第三列可能为奖励，但尚无公式证据。四列应整体保留。
- `[low link character gold bonus]` 在 `etc/linksystem/characlinksystem.etc:13` 为 `1 70 10 0`。`[high link character gold bonus]` 在第 17 行为 `1 70 0 0`。经验与金币各有独立标签，修改金币不能顺手同步经验。

## 修改配方与核对

1. 修改经验时先记录目标数组位置及左右两个值。保持 99 个整数和单一无标签序列。只在已确认位置与等级关系后调整目标值。
2. 修改关联奖励时先确定运行环境使用哪个配置文件。分别记录第一、第二关联或 low、high 角色上下文。没有列语义证据时不能安全改七元组，需保留原值并补运行时证据。
3. 已确认某列后只改该列，保留全部结束标签、CRLF 与 TAB。保留原来的整数类型，不写小数或百分号。
4. 静态核对经验表数量和未改位置。关联块分别核对 7 或 4 个整数。真实打包后重新提取，再在客户端验证等级边界、经验奖励和金币奖励。单跑 `--verify` 不检验修改后的 output。

## 未知项

本页未确认经验表为累计经验还是单级经验，也未确认关联奖励基数与叠加关系。尾部负值不能安全转换为新的更大十进制整数。文档的空格展示不保留源文件 TAB，不能直接粘贴覆盖。
