# 角色与技能功能索引

角色、职业、副职业、成长和技能。

下列叶文档提供基于 output 实际文件的修改步骤。每篇分别记录入口路径、原始 token 形状、字段证据和未确认语义。先按子功能定位，再按文档中的索引和块上下文查找目标。

## 功能范围

- 角色与职业的基础定义。
- 副职业及成长规则。
- 技能定义、职业技能体系及名称索引。
- 角色动作与攻击判定。

## 子功能索引

- [职业与角色定义](professions/FEATURE_MAP.md)。角色职业、职业变体和基础角色配置。
- [技能定义与职业技能列表](skill-definitions/FEATURE_MAP.md)。技能属性、职业技能编目和技能名称索引。
- [技能学习与加点](skill-learning/FEATURE_MAP.md)。技能学习条件、SP 与 TP 分类和自动加点。
- [副职业](expert-jobs/FEATURE_MAP.md)。炼金、分解、控偶和附魔的副职业定义。
- [角色成长与角色关联](character-growth/FEATURE_MAP.md)。角色经验、等级及角色之间的关联配置。
- [角色动作与攻击判定](character-actions/FEATURE_MAP.md)。职业动作、攻击信息及角色公共动作。

## 归类边界

本类记录角色与技能配置。转职、觉醒及副职业任务归入任务与活动。技能树完整界面归入界面与交互。本类的技能学习手册只分析技能 ID 与 SP、TP 树节点的关联。
