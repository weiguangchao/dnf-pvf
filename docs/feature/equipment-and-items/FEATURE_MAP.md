# 装备与道具功能索引

装备、时装、消耗品、材料和物品名称。

下列叶文档提供基于 output 实际文件的修改步骤。每篇分别记录入口路径、原始 token 形状、字段证据和未确认语义。先按子功能定位，再按文档中的索引和块上下文查找目标。

## 功能范围

- 装备与时装的定义及属性。
- 消耗品、材料及其他可堆叠道具。
- 物品价格与名称索引。
- 装备和道具关联的动画表现。
- 强化、增幅、分解与随机词条配置。

## 归类边界

本类记录角色装备与物品定义，以及装备改造配置。商店销售配置归入 NPC 与商店，宠物装备归入宠物，掉落表归入脚本与公共配置。
