# 宠物功能索引

宠物定义、成长、技能和动作。

叶子手册分别核对 creature 编目与基础定义、顶层和节点式技能、经验与装备，以及独立 pet 格式。具体字段和样例见各手册。路径均相对 output，观察结构与推断玩法分别说明。

## 功能范围

- 宠物定义与索引。
- 宠物经验与成长。
- 宠物技能、攻击和动作。
- 不同宠物系统的功能边界。
- 宠物装备与宠物成长配置。

## 子功能索引

- [宠物种类与基础定义](creature-definitions/FEATURE_MAP.md)。宠物种类、基础参数和宠物编目。
- [宠物技能、动作与台词](creature-skills-and-dialogue/FEATURE_MAP.md)。宠物普通技能、终结技能、动画和对白。
- [宠物成长与装备](creature-growth-and-equipment/FEATURE_MAP.md)。宠物经验、进化字段和宠物装备。
- [独立 pet 系统](legacy-pet-system/FEATURE_MAP.md)。独立于 creature 编目的 pet 定义。

## 归类边界

本类分别记录 creature 与 pet 两套编目。宠物生成的战斗对象归入战斗对象与状态效果，宠物窗口归入界面与交互。
